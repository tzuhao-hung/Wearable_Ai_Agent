# Stress AI Agent

This project generates simulated physiological data (like heart rate, skin temperature, and EDA) and uses GPT to estimate the user's stress level. The goal is to provide a lightweight, demo-ready agent that can show how wearable data might be used to give stress feedback.

---

## What it does

- Generates random but realistic samples (HR, TEMP, EDA, movement)
- Uses GPT to analyze and assign a stress level: **Low**, **Medium**, or **High**
- Gives simple, human-friendly suggestions based on the results

Example output:
Sample 1:

HR: 96 bpm

TEMP: 36.9 °C

EDA: 0.62 μS

Stress Level: High 

Summary: Your heart rate and EDA are elevated, which might suggest stress. Try taking a short walk or some deep breaths.
